- **图鉴系统**（人物观察 / 背包 / 状态页）· **独立存档界面** · **选项外观可调** · **自定义字体**

## 一、怎么打开

**在线版**：<https://khb10533.github.io/wenyu/>

用手机浏览器打开就行。建议做一步：浏览器菜单 →「**添加到主屏幕**」——
之后它有图标、全屏打开，而且**断网也能用**（全站已被缓存到本地）。

想先看看这东西能做成什么效果，可以直接玩示例游戏
[《雾港三日》](https://khb10533.github.io/wenyu/dist/demo.html)：
19 场景 · 3 个结局 · 3 个立绘角色 · 3 套表情差分 · 4 处情绪气泡 · 图鉴 3 页。
在编辑器里点左上角 **☰ → 工程库** 也能打开它。

**所有数据都存在你自己的浏览器里**，不联网、不上传。
换设备或清浏览器数据会丢，重要的作品记得用「导出工程文件」备份。

### 自己部署 / 离线使用

整个项目就是一堆静态文件，**没有任何构建步骤**，扔到任意支持 HTTPS 的
静态托管上就能跑（GitHub Pages、Cloudflare Pages、Netlify 都行）。

想本地预览，在项目目录里起一个静态服务：

```bash
python3 -m http.server
```

然后浏览器打开它提示的那个地址（默认是 `http://localhost:8000/`）。

> 必须用 `localhost` 或 HTTPS：Service Worker 只能在安全上下文里注册，
> 少了它就没有「添加到主屏幕」和离线可用。上面那些托管默认都是 HTTPS。

## 三、写一场戏

点「剧情」里的场景卡片，**场景编辑器顶部有四个页签**：

### 📄 正文
场景备注（只有你看得到）、正文、页签上实时显示字数。

### 🎭 演出
舞台演出入口、**这一场谁在说话**、背景图、背景音乐、进入这一场时的数值变化。

### 🔀 选项
加分支、选去向、设显示条件、设选中效果、勾「只能选一次」。

### 🎬 结局
点「**✓ 把这一场设为结局**」再填名字即可。下面有「**本作全部结局**」汇总，点一下就能跳过去改。

> 故事至少得有一个结局，否则玩家走到最后会卡住。「剧情」页的「✓ 检查」会列出所有这类问题。

## 四、图鉴（人物观察 / 背包 / 状态）

这是这一版的重点，也是**顶部变量条的替代方案**。

以前数值一直挂在屏幕顶上，很挡画面。现在改成：**作者定义几个资料页，玩家点菜单自己翻**。

### 4.1 建页

「图鉴」页里有三个快捷按钮：

| 页 | 类型 | 内容 |
|---|---|---|
| 👤 **人物** | 条目卡片 | 角色卡：立绘 + 名字 + 介绍 + 好感度 |
| 🎒 **背包** | 条目卡片 | 道具：图标 + 名字 + 说明 |
| 📊 **状态** | **数值表** | 自动列出你所有「不隐藏」的变量，不用一条条维护 |

新工程**自带一个「状态」页**，所以新手点开菜单立刻就有东西看。

### 4.2 条目怎么设

点「＋ 新条目」，能设：

- **名称** —— 玩家看到的名字
- **配图** —— 人物卡用立绘，道具用图标，都可以
- **说明** —— 一段介绍文字
- **在这张卡上显示哪些数值** —— 勾上「好感」，玩家就会在这张卡上看到好感的实时值
- **什么时候解锁** —— 不设 = 一开始就能看到；设了条件没满足时显示成「？？？」（也可以设成直接隐藏）

人物卡长得像这样：

```
┌────────┬──────────────────────┐
│        │ 阿萤                 │
│  立绘  │ [好感 7] [线索 3]     │
│        │ 药店老板的女儿……     │
└────────┴──────────────────────┘
```

### 4.3 数值显示在哪，由你定

「变量」页里每条变量都有「**玩家看得到吗**」：

| 选项 | 效果 |
|---|---|
| 不显示 | 纯内部数值（隐藏的真相、计数器） |
| **只在图鉴 / 状态里** | 玩家点开菜单才看得到（**推荐**，也是默认） |
| 顶部常驻显示 | 一直挂在画面顶上（现在默认不用了） |

## 六、选项：逐个拖，图片自己传

### 6.1 每个选项都能单独拖

「设置 → 选项的样子 → 出现的位置」选「**自由摆放**」，然后去「**演出 → 舞台演出**」：

- 每切到一个场景，**这个场景的每个选项都会各有一个虚线块**
- **直接拖**其中任何一个，就改它自己的位置
- 新场景的选项会先按整块的位置依次排开，拖过之后就记住了

> 不用先去设置里改：**在第一层虚线块上拖一下，会自动切成逐个摆放**，
> 并且把当前场景的选项按原样铺开，接着逐个拖就行。

坐标是归一化的，换任何屏幕尺寸都不会跑偏。示例《雾港三日》里，
「阿萤」那场的三个选项就是分别摆在左上、右中、左下的。

> **拖动块是照真实素材画的** —— 你选的选项框图片会直接显示在虚线块里，
> 这样「让选项融进背景」这种对齐才做得准。虚线框本身是中性的，不带颜色。

### 6.2 四个固定位置（懒人用）

| 位置 | 说明 |
|---|---|
| **画面正中** | **默认**。选项浮在立绘上、对话框还留在底部 —— 最不容易挡住人物 |
| 对话框下方 | 最传统的排版。注意：选项会把对话框往上顶，人物被挡得更多 |
| 贴着画面底部 | 压在最下面 |
| 自由摆放 | 自己拖 |

再配 **形状**（长条 / 卡片 / 纯文字 / 带序号）、**对齐**、**宽度**。
改完点「▶ 去试玩看看样子」立刻能看到。

### 6.3 每一场可以单独设

不是每一场都适合同一个位置。在「**选项**」页（或「演出 → 舞台演出」里）有一个
「**这一场的选项出现在哪**」，可以**只改这一场**，留空就跟着全局走。

示例《雾港三日》就是：全局用「画面正中」，只有「阿萤」和「第二天」两场单独用「逐个摆放」。

### 6.4 选项的素材图

分两级：

**① 项目级**：设置里的「**选项框素材**」—— 选一张图，所有选项都用它当边框/底板。
示例游戏里那个半透明带描边的框就是这么来的。

> 铺法有两种，选错会让图变形：
> - **九宫格**（默认）：四个角原样保留，中间拉伸。**带圆角、带花边的边框图必须用这个**。
> - **拉伸铺满**：整张图拉满。适合纹理、渐变这类没有明显边角的图。

**② 每个选项自己的图**：在选项卡片里选「**这个选项的图片**」。

- 不勾「只显示图片」→ 图当这个选项的背景（文字盖在图上）
- 勾上「**只显示图片，不显示文字**」→ **整块就是一张图**，按图片本来的比例撑高
  （上传时我会记下图片宽高，所以比例不会走样）

这样就能做「点这张图继续」的效果：画一张门的图、一张窗的图，分别挂到两个选项上。

## 七、对话框：钉在最底下，人物露出来

对话框**固定贴在画面最底下**，旁白和人物说话一视同仁，都不会上下乱跑。

（之前有个 bug：给「说话人名牌」写样式时多加了一句 margin-top，把「钉底」的
margin-top: auto 覆盖掉了 —— 结果**旁白在底部、人物一说话就弹到中间**。已经修好，
并且加了一条 CSS 静态检查专门防这类覆盖。）

长台词怎么办？**在框内滚动** —— 配合「设置 → 界面 → **对话框最高**」限制它最多占多高：

- 数字越小 → 对话框越矮 → **露出来的立绘越多**
- 默认 40（大概占画面五分之二），示例调成了 30
- 范围 20～70

**对话框样式**也两选一：

| 样式 | 样子 |
|---|---|
| **贴边整条**（默认） | 一条紧紧贴着画面最底部的横条，大多数 galgame 的样子 |
| 悬浮圆角卡片 | 两边留白、圆角浮在底部（之前的样子） |

打字的时候框内会自动往下滚，读的人不用手动拨。

> 以前默认是「选项在对话框下方」，选项一多就把对话框往上顶，人物被挡掉一大半。
> 现在默认选项在**画面正中**，对话框自己待在底部，两边互不干扰。

## 八、界面素材：所有地方都能换成你自己的图

内置配色是蓝灰色，跟你的美术放一起大概率不搭。所以**每个界面部位都能换**：

「设置 → 界面素材」里可以给这些位置各自指定一张图：

| 部位 | 说明 |
|---|---|
| **对话框底图** | 对话框那一整条的底图 |
| **说话人名牌** | 名字那个小牌子 |
| **选项框** | 在「选项的样子」里单独设，还能逐个选项覆盖 |
| **图鉴卡片底** | 人物 / 背包 卡片的底板 |
| **存档格底** | 存档位那一格 |
| **菜单 / 设置面板底** | 菜单弹层的底 |

留空就用内置样式；填上就整套换掉。

**铺法两选一**（「素材怎么铺」）：

- **九宫格**（默认）：四角原样保留、中间拉伸。**带边框、带花边的图必须用这个**
- **拉伸铺满**：适合纹理、渐变这类没有明显边角的图

> 顺带修掉了一个碍眼的东西：以前每个选项都有一条**强调色（默认蓝）的 1px 描边**，
> 换上自己的素材后它会露在图片外面，看着很突兀。现在改成中性色，有素材图时直接透明。
> 舞台编辑器里的选项拖动块也从蓝色虚线改成了中性虚线。

## 九、横屏 / 竖屏

「设置 → 界面 → **屏幕方向**」：竖屏 / 横屏 / 跟随设备。

### 关键：游戏跑在一个固定比例的画布里

网页**没有办法强制手机转屏** —— 浏览器不允许。所以「横屏游戏」不能靠锁方向来实现，
而是靠**固定比例画布**：

| 设置 | 游戏画布 | 效果 |
|---|---|---|
| 竖屏 | 9 : 16 | 在宽屏上左右留边 |
| 横屏 | 16 : 9 | 在竖屏手机上上下留边，画面完整不变形 |
| 跟随设备 | 铺满 | 完全自适应 |

也就是说：**横屏游戏在任何设备上都能正常玩**。手机横过来就占满全屏；
竖着拿就是中间一个宽画面，四周留边，还能点掉提示先这么玩。

导出的游戏也会**尽力**锁定方向（全屏 / 已安装 PWA 时才有效），
锁不住就显示可点掉的提示：**点一下就能不管它**，只在手机尺寸下出现，桌面宽屏不会被打扰。

设置成横屏之后，「演出 → 舞台演出」里的画布会变成 16:9 ——
**你在编辑器里看到的就是玩家看到的那一块**，摆位置不会跑偏
（坐标是归一化的，同一套数据横竖屏通用）。

横屏下正文和选项会自动收窄居中，一行不会拉太长。编辑器本身在横屏下也能用（顶栏底栏会自动压扁）。

## 十、自定义字体

「素材」页可以上传 `.ttf` / `.otf` / `.woff` / `.woff2`，
再到「设置 → 界面 → 自定义字体」选用。对话框、选项、图鉴全部会换。

> ⚠️ 字体文件很大，内嵌进游戏后会**再膨胀约 1/3**。
> 一个 5MB 的字体能让导出的 HTML 多出 6～7MB。建议用裁剪过的子集字体。

## 十一、立绘、表情、气泡与关键帧

### 表情差分（恋爱游戏必备）

一个角色可以有多张脸。在「演出 → 舞台演出」里选中角色，下面有「**表情差分**」：

1. 点「**＋ 加表情**」，起个名字（微笑 / 生气 / 害羞…），再选一张图
2. 点表情名就能在画布上**预览**那张脸

然后在**进入场景时**或**选中某个选项时**加一条效果，操作选「**换表情**」，
再选角色和表情就行。例如：

> 玩家选了「蹲下去帮她捡」→ 阿萤 换成「微笑」

角色的表情会跟着存档一起存下来，读档回到那一刻还是那张脸。

> 示例《雾港三日》里阿萤有 3 套表情（微笑 / 难过 / 惊讶），剧情里用了 6 处「换表情」。
> 这几张脸是 `tools/sprites.mjs` 用同一套画法换眼睛和嘴生成的。

### 情绪气泡（「！」「？」「♡」这种）

在「演出 → 舞台演出」的角色列表下面有「**情绪气泡**」：

1. 点「**＋ 加气泡**」—— 当前选中了角色的话，气泡会自动贴到他头顶附近
2. 选一张图。**PNG 或 GIF 都行** —— GIF 会直接动起来
3. 选「动作」：不动 / 弹出来 / 闪烁 / 上下飘 / 左右抖 / 一缩一放
4. 设「第几毫秒冒出来」和「持续多久」（0 = 一直到本场结束）
5. **画布上可以直接拖**，拖到角色头顶就行

> 图本身是动图的话，「动作」选「不动」就好 —— 别两层动画打架。

示例里用了 4 处：发现你在看她时「！」弹出来、你帮她捡药包时「♡」上下飘、
你站着不动时「汗」在闪、第二天又见面时「？」弹出又消失。

### 放一个角色

1. **素材** → 上传一张**透明背景的 PNG**（立绘）
2. 场景 → 「演出」页 → 「舞台演出」→「＋ 添加角色」

### 一键预设

| 替换型 | 追加型 |
|---|---|
| 直接出现 · 左右滑入 · 淡入 · 弹出放大 | 滑出退场 · 淡出退场 · 左右抖动 · 平移到当前帧 |

前 4 个一键做出场，后 4 个接在末尾。所以「从左边滑进来 → 抖一下 → 淡出消失」是点三下的事。

### 直接对着图编辑

- **在画布上拖动立绘** → 直接改位置，拖完自动在当前时刻打一个关键帧
- 时间轴滑块选时刻，**▶ 播放**预览整段演出
- 缩放 / 不透明度滑杆、左右翻转、前后层级

### 原理

每个角色一条**关键帧轨道**，播放器在相邻两帧之间**自动补间**（位置、缩放、透明度）。
第一个关键帧之前角色还没上场（所以打帧 = 定进场时机），最后一帧之后保持。
缓动可选：先快后慢 / 匀速 / 两头慢 / 先慢后快。

## 十二、怎么给别人玩

### 🎮 导出可分享的游戏 → `游戏名.html`

**单个 HTML 文件**，图片、立绘、音乐、图鉴全部内嵌。发给任何人，对方用手机浏览器打开**直接就能玩**，
不用装东西、不用联网，立绘演出、图鉴、存档全是好的。

### 📤 导出工程文件 → `游戏名.wy`

你自己的工程备份，含全部素材。只有装了本工具的人能打开继续编辑。

### 📥 反过来：导入

**☰ → 工程库 → 从文件导入**，可打开 `.wy` 工程，也可打开别人分享的 `.html` 游戏，还原成可编辑的工程。

## 十三、目录结构

```
wenyu/
├── index.html              入口
├── manifest.webmanifest    PWA 清单
├── sw.js                   Service Worker（离线缓存）
├── css/
│   ├── app.css             编辑器样式
│   ├── player.css          播放器 + 舞台 + 图鉴 + 存档样式（导出的游戏也用它）
│   └── fallback.css        不支持 color-mix() 的老浏览器兜底
├── js/
│   ├── format.js           数据格式 + 规则引擎 + 关键帧补间 + 图鉴模型（纯函数，可单测）
│   ├── store.js            本地存储（IndexedDB 存工程，localStorage 存存档）
```

## 十五、已知限制

- **立绘得自己准备**。`tools/sprites.mjs` 程序画的那几个只是占位，让你立刻看到效果。
- **立绘是静态图片**，靠位置/缩放/透明度做演出。**不是 Live2D、不是骨骼动画**，不会眨眼呼吸。
- **存档缩略图是现场画的**（背景 + 立绘），不是真正的屏幕截图 —— 对话框上的文字不会出现在缩略图里。
- **字体很占体积**，见上面第七节的提醒。
- **数据存在浏览器里**。清理浏览器数据会连工程一起清掉，重要的记得「导出工程文件」备份。
- **素材别太大**。图片建议单张 500KB 以内；总量超 8MB 时导出的游戏会很大。
- 没做加密，`.wy` 和导出的 HTML 都是明文。
- **横屏靠固定比例画布实现**，不是强制转屏（浏览器不允许）。
  竖屏手机上看横屏游戏，画面会缩小居中并留边 —— 完整、不变形，但小。
  真正的全屏体验要靠「添加到主屏幕」后全屏运行。
- **表情差分和气泡都要你自己准备图**。示例里那些是程序画的占位；
  实际做游戏应该画同一角色的多张表情立绘，气泡可以用现成的表情包 GIF。
- 界面素材能换的部位是「对话框 / 名牌 / 选项框 / 图鉴卡 / 存档格 / 菜单面板」这几处，
  底部按钮之类的还没开放。
- 单工程几十个场景、十几个角色没问题；上千场景没测过。

## 十六、如果想要真正的 APK

现在是 PWA（网页应用 + 添加到主屏幕），日常用起来和 App 没区别。
若确实要 `.apk`，用 [Capacitor](https://capacitorjs.com/) 套壳即可，**代码一行不用改**——
需要自己准备 JDK 和 Android SDK（约 2 GB），编译也要花点时间。
